# Nav stack images

Screenshots referenced by the
[nav-stack README](/software/ros_ws/src/nav-stack/README.md).

## Base station screenshot

`base_station_rviz.png` starts as a generated placeholder. Replace it with a
screenshot of the RViz window from `base_station.launch.py` during autonomous
navigation, **keeping the same file name**, and the README picks it up without
any edits. About 1600 × 900 works well.

## Screenshot tips

- Use a dark RViz background so the screenshot reads well in both GitHub
  themes.
- Keep the file under about 2 MB. Running it through `pngquant` or `oxipng`
  usually gets it well under that.
- To add more images later, drop them in this folder and reference them from
  the nav-stack README as `images/<name>.png`.
